# Folio.jm — Joshua Mendonza

Personal portfolio website built as a real project, not just a template.

**Live:** https://mendonzajoshua.github.io/folio-jm

## Built with

- HTML5 + Tailwind CSS (CDN) + Vanilla JavaScript
- GitHub REST API for live repository feed
- EmailJS for serverless contact form
- Playfair Display + DM Sans typography

## Features

- Single-page scroll with smooth section navigation
- Dark / light mode with localStorage persistence
- Scroll-triggered animations via Intersection Observer
- Animated skill bars
- Live GitHub repository feed
- AI-assisted planning and development workflow

## Run locally

No build step needed. Clone and open `index.html` in any browser,
or use VS Code Live Server for hot reload.
