05 — Projects

Things I've

Featured

Final Year Project · Group of 3

WayPal

A voice-guided indoor navigation app for visually impaired users. ESP-32 BLE beacons act as checkpoints to detect user position in real time. The Flutter app uses an audio-first interface, no visual interaction needed with Speech-to-Text and Text-to-Speech. Includes a hybrid GPS module for outdoor-to-indoor transitions. A custom 3D-printed enclosure for the beacon hardware was designed and built by our project guide, Prof. Aaron Sir. Presented at a technical exhibition.

ESP-32 BLE Flutter IoT Arduino C++ STT / TTS EMA Filter
Three of us built this together. Working with physical hardware ESP-32 boards, BLE signal ranges, beacon placement on real corridors was completely different from writing code on a laptop. The hardest problem wasn't the code; it was signal noise. When we finally got the EMA filter stabilising the beacon detection and heard the app say the right direction out loud, that was the moment. Presenting the prototype at the exhibition and explaining it to people who actually understood what it meant for accessibility that's a memory that stays.
