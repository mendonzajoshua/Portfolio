Final Year Project · Group of 3

WayPal

A voice-guided indoor navigation app for visually impaired users. ESP-32 BLE beacons act as checkpoints to detect user position in real time. The Flutter app uses an audio-first interface, no visual interaction needed with Speech-to-Text and Text-to-Speech. Includes a hybrid GPS module for outdoor-to-indoor transitions. A custom 3D-printed enclosure for the beacon hardware was designed and built by our project guide, Prof. Aaron Sir. Presented at a technical exhibition.

ESP-32 BLE Flutter IoT Arduino C++ STT / TTS
Three of us built this project together. Working with physical hardware, BLE signal ranges, and beacon placement in actual corridors was completely different from writing software on a laptop. The hardest part was handling signal noise and inconsistent beacon detection. After implementing the EMA filter and stabilising the detection system, hearing the app correctly announce directions as a user passed each checkpoint felt like the moment the project finally came together. Presenting the prototype at the exhibition and explaining its accessibility impact to others was one of the most rewarding experiences from the project.
